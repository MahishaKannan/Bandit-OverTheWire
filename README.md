# Bandit OverTheWire – 15 Levels

## About

This repository contains my learning journey through the OverTheWire Bandit challenge.

I have documented my work from Level 0 to Level 14 using my commands, steps, results and terminal screenshots.

The purpose of this repository is to record my practical learning and help beginners understand the basic Linux and cybersecurity concepts used in the Bandit challenge.
